# 审核人员测试说明

目标版本：**以 `manifest.json` 中声明的当前版本为准**

## 无账号公开测试

使用以下公开 arXiv DOI：

- `10.48550/arXiv.2010.08895`
- `10.48550/arXiv.2109.03697`

## 测试步骤

1. 安装扩展，确认首次引导页自动打开；点击“显示全部说明”时，应在同一页面展开全部内容；
2. 在引导页或主面板下载/复制内嵌示例 CSV，该功能不依赖外部服务器；
3. 打开批量下载页；
4. 设置子文件夹，例如 `freepaper_review_test`；
5. 粘贴两个 DOI，并故意重复粘贴其中一个；
6. 确认程序显示唯一文献数小于原始记录数；
7. 启动下载；
8. 确认 PDF 进入设置的子文件夹；
9. 确认同一 DOI 不产生重复文件；
10. 确认“最近下载”只列出 Freepaper 创建的文件，或当前人工验证任务明确触发并关联的 PDF；无关下载不会出现；
11. 导出结果 CSV；
12. 若存在失败项，点击精准重试，确认成功项不会重新下载。

## ScienceDirect 说明

ScienceDirect 页面可能要求机构权限、VPN或人工验证。Freepaper可对明确识别的 View PDF / Download PDF 入口自动尝试一次，但不会自动操作验证码或机构登录；需要人工操作时会暂停并在完成后恢复。Freepaper不绕过这些要求。审核核心功能无需 ScienceDirect 测试账号，公开 arXiv 流程即可完成。


## 动态 PDF 防护

IEEE、Wiley、ScienceDirect 和知网的动态 PDF 地址不会直接交给浏览器下载 API 二次请求。扩展会先在已登录论文页面上下文中检查 `%PDF-` 文件头；测试过程中不应出现 `stamp.htm` 或 `init.htm`。若站点禁止页面内自动保存，扩展会保留 PDF 查看器并等待用户使用查看器下载按钮。
