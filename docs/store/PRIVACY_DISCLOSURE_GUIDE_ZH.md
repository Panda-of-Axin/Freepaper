# 商店隐私披露填写提示

此文件是填写后台表单的操作提示，不是法律意见。提交时应以扩展当时的实际代码行为为准。

## 当前代码行为

- 不向开发者服务器发送 DOI、URL、页面内容、登录信息或下载历史；
- 不使用广告、分析或跟踪 SDK；
- 在用户设备本地处理论文页面 URL、标题、链接和状态；
- 直接与 DOI 服务、出版商网站和 PDF 托管网站通信；
- 在浏览器本地保存设置和任务状态；
- 不读取密码，不导出 Cookie；
- “最近下载”只保存 Freepaper 自己登记的下载。

## Chrome Web Store

- 填写准确的 Single purpose；
- 在 Privacy practices 中逐项核对网页内容、浏览活动和本地处理相关问项；
- 明确说明数据不传输给开发者或第三方；
- 提供公开、最新的隐私政策 URL；
- Limited Use 认证必须与代码和隐私政策一致。

## Edge Add-ons

- 在 Properties/Privacy 中如实说明扩展是否访问网页内容或用户提供的 URL；
- 提供公开隐私政策 URL；
- 在 Notes for certification 中说明公开 arXiv 测试流程和 ScienceDirect 权限边界；
- 不要选择与实际代码行为矛盾的“完全不访问任何信息”等选项。
