## 仍需从真实扩展中截图

请使用实际运行中的 v1.4.0 界面截图，不要使用合成或过期版本。

### Microsoft Edge Add-ons

- 可用尺寸：640×480 或 1280×800；
- 英文和简体中文商店页建议分别上传对应语言截图；
- 建议展示：当前页面、批量下载/总控台、验证助手。

### Chrome Web Store

- 推荐 1280×800；
- 也支持 640×400；
- 可在商店后台的语言选择器中分别上传本地化截图。

截图前请隐藏个人账号、机构名称、VPN/登录状态、本地路径、私人论文清单和无关浏览器标签页。
