# Store submission documents

[English](#english) · [简体中文](#简体中文)

## English

Freepaper uses one Chromium Manifest V3 runtime package for Microsoft Edge and Google Chrome, but each store requires a separate listing and review submission.

The package contains `_locales/en` and `_locales/zh_CN`, so both stores can expose English and Simplified Chinese listing locales.

- Edge English template: [`EDGE_ADDONS_SUBMISSION_EN.md`](EDGE_ADDONS_SUBMISSION_EN.md)
- Edge Chinese template: [`EDGE_ADDONS_SUBMISSION_ZH.md`](EDGE_ADDONS_SUBMISSION_ZH.md)
- Chrome English template: [`CHROME_WEB_STORE_SUBMISSION_EN.md`](CHROME_WEB_STORE_SUBMISSION_EN.md)
- Chrome Chinese template: [`CHROME_WEB_STORE_SUBMISSION_ZH.md`](CHROME_WEB_STORE_SUBMISSION_ZH.md)
- Permissions: [`PERMISSIONS_JUSTIFICATION.md`](PERMISSIONS_JUSTIFICATION.md)
- Reviewer instructions: [`REVIEWER_TEST_INSTRUCTIONS.md`](REVIEWER_TEST_INSTRUCTIONS.md)
- Localization workflow: [`LOCALIZATION_GUIDE.md`](LOCALIZATION_GUIDE.md)
- Assets checklist: [`STORE_ASSETS_CHECKLIST.md`](STORE_ASSETS_CHECKLIST.md)

## 简体中文

Freepaper 的 Edge 与 Chrome 版本使用同一个 Chromium Manifest V3 运行包，但必须在两个商店后台分别创建条目并提交审核。

运行包包含 `_locales/en` 与 `_locales/zh_CN`，因此两个商店都可以提供英文和简体中文页面。
