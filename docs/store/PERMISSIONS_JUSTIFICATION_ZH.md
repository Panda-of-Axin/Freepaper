# 权限用途说明

以下内容可用于 Edge Add-ons 的认证备注或 Chrome Web Store 的 Privacy practices / 权限说明。

## `downloads`

用于创建 PDF 下载、指定下载子文件夹、读取 Freepaper 自己创建的下载任务状态；当且仅当当前任务正在等待用户完成验证或手动 PDF 操作时，还会观察新建下载事件，并仅将出版商来源或文件名/论文标题与当前任务明确匹配的 PDF 关联为任务结果。不会枚举、扫描或展示无关的普通浏览器下载历史。

## `storage`

用于在用户设备本地保存设置、批量队列、任务恢复状态、人工验证状态和 Freepaper 下载历史。数据不会上传到开发者服务器。

## `activeTab`

用户点击扩展并主动扫描当前页面时，临时访问当前标签页以检测 PDF 候选。

## `tabs`

用于打开 DOI 或论文链接、跟踪批量任务对应的标签页、切换回需要用户操作的任务页面。

## `scripting`

用于在用户请求处理的论文页面中检测 PDF 链接、页面类型和明确的验证码、登录或机构认证状态，并在实际任务页显示操作助手。不会用于修改无关网页或注入广告。

## `webNavigation`

用于跟踪 DOI 重定向、出版商登录/验证跳转、文章页到 PDF 页的切换，并避免因多次导航事件产生重复任务。

## `alarms`

Manifest V3 Service Worker 可能被浏览器回收。该权限用于定期恢复和清理未完成任务状态，不用于用户跟踪或后台联网分析。

## `<all_urls>`

Freepaper 接受用户主动输入的 DOI 和不同出版商 URL。论文及 PDF 可能位于大量不同域名，因此需要跨站点访问权限来打开用户指定页面、检测 PDF 并完成下载。该权限仅用于用户明确发起的论文下载工作流，以及在实际任务页需要人工操作时显示助手；Freepaper 不收集或上传一般浏览活动。
